# ПК-портфель

Домашний сайт, который следит за ценами комплектующих твоего компьютера в [DNS](https://www.dns-shop.ru)
и показывает сборку как инвестиционный портфель: сколько вложил, сколько сборка стоит сейчас,
на сколько процентов подорожала каждая деталь и вся сборка, и график как у акций.

- Раз в день (время настраивается) открывает страницы товаров в DNS и записывает цены.
- Хранит всю историю цен в SQLite, так что график растёт вместе с данными.
- Показывает изменение в рублях и процентах за всё время и за день, мини-график каждой детали
  и подробную карточку с историей проверок.
- Цену можно записать вручную или отправить со своего браузера закладкой, если DNS не пускает Pi.
- Работает в Docker на Raspberry Pi 4/5 (64-битная ОС).

## Запуск на Raspberry Pi

Нужна **64-битная** Raspberry Pi OS (Chromium от Playwright собран только под arm64) и хотя бы 2 ГБ памяти.

```sh
# один раз: Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER   # перелогиниться после этого

git clone https://github.com/antoniocra04/pc-invest-board.git
cd pc-invest-board
docker compose up -d --build
```

Сайт откроется на `http://<адрес-pi>:8080`, например `http://raspberrypi.local:8080`.
Данные лежат в `./data` рядом с `docker-compose.yml`: база `board.sqlite3` и профиль браузера.
Для бэкапа достаточно скопировать эту папку.

Обновление: `git pull && docker compose up -d --build`.

## Настройки

В `docker-compose.yml`, секция `environment`:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TZ` | `Europe/Moscow` | Часовой пояс для расписания и дат |
| `CHECK_TIMES` | `10:00` | Когда проверять цены, через запятую: `10:00,22:00` |
| `DNS_CITY` | пусто | Город DNS (кука `city_path`, например `moscow`). Цены в DNS зависят от города; пусто — DNS определит по IP |
| `BROWSER` | `camoufox` | Каким браузером ходить в DNS: `camoufox` (Firefox с отпечатком обычного ПК) или `chromium` (Chromium через patchright) |
| `HEADLESS` | `0` | `1` — браузер без виртуального экрана: легче, но антибот блокирует чаще |
| `SCRAPE_DELAY_MIN` / `SCRAPE_DELAY_MAX` | `8` / `20` | Пауза между товарами в секундах, чтобы не долбить магазин |

Если Pi был выключен во время проверки, она запустится через пару минут после старта контейнера.

## Как добавить комплектующие

Кнопка **«+ Добавить»**: ссылка на товар в DNS, цена покупки за штуку, количество и дата покупки.
Название можно не писать, оно подтянется со страницы DNS при первой проверке.
Детали, которых нет в DNS, тоже можно добавить: без ссылки, цену тогда записываешь вручную.

Списком через API:

```sh
curl -X POST http://raspberrypi.local:8080/api/import \
  -H 'Content-Type: application/json' \
  -d '{"components": [
    {"url": "https://www.dns-shop.ru/product/xxxxxxxxxxxxxxxx/.../", "category": "Видеокарта",
     "purchase_price": 89999, "purchase_date": "2026-03-01"},
    {"name": "Термопаста", "purchase_price": 490, "purchase_date": "2026-03-01", "quantity": 1}
  ]}'
```

## Про антибот DNS

У dns-shop.ru стоит защита Qrator: обычный HTTP-запрос получает 401 и JS-проверку, а браузер,
который она сочтёт роботом, получает страницу «HTTP 403 — Доступ к сайту запрещён».
Обычный Playwright Chromium на Raspberry Pi она распознаёт, поэтому в образе два браузера получше:

- **Camoufox** (по умолчанию) — сборка Firefox, которая выдаёт себя за обычный компьютер;
- **Chromium через patchright** — форк Playwright, который прячет следы управления браузером.

Оба работают на виртуальном экране Xvfb, профиль с куками антибота сохраняется между запусками.
Из дата-центров DNS не пускает никого, с домашнего IP шансы нормальные.
Если DNS ответил 403, проверка сразу останавливается, чтобы не продлевать блокировку.

Какой браузер DNS пускает, можно проверить одной командой (займёт минуту-две):

```sh
docker compose exec pc-invest-board python -m app.probe https://www.dns-shop.ru/product/<код>/
```

Команда пробует оба браузера и пишет для каждого «OK, цена …» или что пошло не так.
Тот, что прошёл, ставь в `BROWSER` в `docker-compose.yml`.

Если проверка всё равно упирается в антибот (в таблице будет «ошибка» с пояснением), есть запасной путь:
**закладка «В ПК-портфель»** внизу страницы. Перетащи её на панель закладок, открой товар на dns-shop.ru
в своём браузере (с компьютера в домашней сети) и нажми закладку. Цена запишется в портфель, а если такого
товара ещё нет, откроется форма добавления.

Разметка DNS может поменяться. Если проверка пишет «Цена на странице не найдена», открой карточку детали:
там будут ссылки на скриншот, HTML и ответы DNS, которые видел браузер (лежат в `data/debug/`).
По ним видно, что поменялось; правка обычно нужна в `app/dns.py`
(селекторы `.product-buy__price` и `.product-card-top__title`, ответ `/ajax-state/product-buy/`).

## Почему нет входа в аккаунт DNS

Автоматически забрать историю покупок из личного кабинета не получится: вход в DNS только по телефону
и SMS-коду, публичного API нет, а сам кабинет закрыт тем же антиботом. Поэтому покупки вносятся руками
(один раз), а цены дальше собираются сами.

## Разработка

```sh
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
playwright install chromium
pytest
DATA_DIR=./data uvicorn --factory app.main:create_app --reload --port 8080
```

Устройство:

- `app/dns.py` — разбор страницы товара DNS (чистые функции, покрыты тестами)
- `app/scraper.py` — Chromium через Playwright
- `app/updater.py` — запуски проверок и расписание
- `app/portfolio.py` — расчёт стоимости портфеля и рядов для графиков
- `app/main.py` — API на FastAPI
- `app/static/` — интерфейс, графики на [TradingView Lightweight Charts](https://www.tradingview.com/lightweight-charts/)
